# صفَحات

أدوات PDF تعمل محليًا على Windows، بالعربية والإنجليزية.

## التنزيل والتشغيل

نزّل ملف Safahat-3.1-windows.zip من صفحة الإصدارات:
https://github.com/SaadAlzare/safahat-releases/releases/latest

فك ضغط الحزمة كاملةً، ثم شغّل صفحات-3.1.exe. لا تنقل ملف التشغيل وحده؛ المحركات والمكتبات المرفقة لازمة لعمل الأدوات.

تدعم الحزمة Windows بنواتي 64 و32 بت، وARM64. تتطلب .NET Framework 4.5 أو أحدث، و4.8.1 للتشغيل الأصلي على ARM64.

يحتوي هذا المستودع على ملفات توزيع البرنامج فقط. الكود المصدري خاص.
