# Safahat

Offline PDF tools for Windows, available in Arabic and English.

Download Safahat-3.3.5-Setup.exe from:
https://github.com/SaadAlzare/safahat-releases/releases/latest

Run Setup, allow the Windows administrator prompt, and follow the wizard. The default installation folder is Program Files (x86)\Safahat. Desktop shortcuts are enabled by default. The installer includes .NET Framework and the processing engines for offline installation.

For portable use, extract Safahat-3.3.5-portable.zip in full and run صفحات.exe. Keep the executable with its bundled engines and libraries. Application filenames stay the same across updates; the version is available inside the app and in Windows file properties.

The separate Safahat-3.3.5-windows.zip is a small compatibility update for older installed versions. It is not a standalone portable distribution.

Supports Windows 10/11 on x86 and x64, and Windows 11 on ARM64.

This repository contains distribution files only. Source code is private.
