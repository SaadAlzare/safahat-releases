# صفَحات

أدوات PDF تعمل محليًا على Windows، بالعربية والإنجليزية.

## التنزيل والتثبيت

نزّل **Safahat-3.3-Setup.exe** من [أحدث إصدار](https://github.com/SaadAlzare/safahat-releases/releases/latest)، ثم افتحه واتبع معالج التثبيت المعتاد.

يحتوي المثبّت على محركات البرنامج و.NET Framework المطلوب، ويثبت المتطلبات تلقائيًا عند الحاجة دون تنزيلات إضافية. يضيف البرنامج إلى قائمة ابدأ وإعدادات إزالة البرامج، مع خيار اختصار سطح المكتب. قد يطلب Windows صلاحيات المسؤول لتثبيت .NET أو إعادة التشغيل.

يدعم Windows 10/11 بنواتي 64 و32 بت، وWindows 11 على ARM64. تتوفر حزمة ZIP محمولة أيضًا؛ فكّها كاملة وشغّل صفحات-3.3.exe.

يحتوي هذا المستودع على ملفات توزيع البرنامج فقط. الكود المصدري خاص.
